
# 🔐 Operação Enigma Final

> **Nem toda imagem é apenas uma imagem. Nem todo arquivo é o que parece.**

## 📜 Sobre o Projeto

A **Operação Enigma Final** é um desafio de programação desenvolvido em **Java**, no qual o objetivo é reconstruir um sistema de decodificação capaz de desvendar um **Cofre Digital** escondido nos servidores da faculdade.

O projeto envolve diferentes técnicas de segurança e conceitos de **Programação Orientada a Objetos (POO)** para encontrar a mensagem final.

## 🕵️ O Desafio

Para abrir o Cofre Digital, é necessário solucionar uma sequência de desafios envolvendo:

* 🔓 Criptografia e decodificação
* 👁️ Esteganografia
* 🎨 Manipulação de pixels e canais de cor
* 🧩 Estrutura baseada em UML
* 🔗 Interfaces e polimorfismo
* 📦 Encapsulamento
* ♻️ Strategy Pattern

## 🛠️ Tecnologias

* **Java 11+**
* Programação Orientada a Objetos
* Strategy Pattern
* Criptografia
* Esteganografia
* Processamento de imagens

## 📂 Estrutura

```text
src/
└── ...
```

A estrutura do projeto segue o **Diagrama de Classes UML** fornecido para o desafio.

## 🎯 Objetivo

Implementar os decodificadores, integrar suas funcionalidades por meio de polimorfismo e solucionar todas as pistas até revelar a **mensagem final do Cofre Digital**.

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

2. Entre na pasta:

```bash
 Operação Enigma 
```

3. Compile e execute o projeto utilizando **Java 11 ou superior**.

## 📚 Conceitos Praticados

Este projeto foi desenvolvido para colocar em prática conceitos fundamentais de POO, incluindo:

**Encapsulamento • Abstração • Interfaces • Polimorfismo • Strategy Pattern**

Além disso, permite explorar conceitos básicos de **criptografia, esteganografia e processamento de imagens**.
