# 🔐 Operação Enigma: O Cofre do Ex-Aluno

> *"Há rumores de que um ex-aluno brilhante escondeu a chave para um cofre digital direto nos arquivos deste repositório abandonado. O código legado falhou. A única forma de recuperar a informação é reconstruindo os decodificadores esquecidos."*

Bem-vindos à Operação Enigma. Este não é um exercício comum. Para chegar ao final, sua equipe precisará de engenharia reversa, análise estrutural e muita programação orientada a objetos.

## 🎯 Competências Avaliadas
Ao longo desta missão, você testará seus limites em:
- **POO Estrutural:** Implementação de Interfaces e Polimorfismo (Padrão Strategy).
- **Manipulação de I/O:** Leitura de arquivos binários e de texto plano no Java.
- **Criptografia Básica:** Algoritmos de deslocamento (Cifra de César) e codificação em Base64.
- **Processamento de Matrizes:** Manipulação de canais de cores (RGB) usando `BufferedImage`.

## 📜 Regras de Engajamento
1. **Fidelidade ao UML:** A estrutura de classes do seu projeto deve obedecer **RIGOROSAMENTE** ao arquivo de diagrama fornecido pelo professor.
2. **Sem Bibliotecas Externas (Libs):** É estritamente proibido o uso de dependências externas (como Apache Commons, OpenCV, etc). Você deve usar apenas o Java puro (`java.io`, `java.util`, `java.awt`).
3. **Automatização:** A sua `Main.java` deve amarrar todas as etapas. O fluxo deve passar as pistas de um decodificador para o outro programaticamente.

## 🏆 Entrega
A execução final do seu código revelará uma URL secreta. Acesse-a para registrar a vitória da sua equipe!
